# EventPass

Сервис регистрации на мероприятия и прохода по QR-билетам. Это фронтенд MVP по макетам из Figma (секции 01–04: гость, участник, волонтёр, организатор).

## Запуск приложения

Понадобится Docker с Compose. В корне проекта выполните:

```bash
docker compose up --build -d
docker compose ps
```

- Приложение — [localhost:8090](http://localhost:8090).
- Swagger UI — [localhost:8090/api/docs](http://localhost:8090/api/docs).
- Локальная почта — [localhost:8025](http://localhost:8025).

Создайте аккаунт, откройте «Мои мероприятия» и опубликуйте событие. В конструкторе можно выбрать типы вопросов, добавить подсказки, изменить порядок и проверить анкету в режиме гостя или участника. Публичную ссылку можно открыть в отдельном профиле браузера, чтобы зарегистрироваться как гость. Ссылка из письма привязывает гостевой билет к личному кабинету.

### Backend

FastAPI обслуживает REST API, а PostgreSQL хранит аккаунты, мероприятия, билеты, чекины и исходящие задания. Worker передаёт задания через RabbitMQ и обрабатывает их. Письма поступают в Mailpit, PDF билетов хранятся в закрытом S3-бакете SeaweedFS и скачиваются через API после проверки доступа. Nginx раздаёт собранный React и проксирует `/api`.

`docker compose down` останавливает сервисы с сохранением данных в именованных томах. Для другого порта задайте `FRONTEND_PORT` и соответствующий `FRONTEND_URL`. Для внешней почты задайте `SMTP_HOST`, `SMTP_PORT`, `SMTP_FROM`, при необходимости `SMTP_USERNAME`, `SMTP_PASSWORD` и `SMTP_STARTTLS=true`. Локальные пароли PostgreSQL, RabbitMQ и S3 настраиваются переменными `POSTGRES_PASSWORD`, `RABBITMQ_PASSWORD` и `S3_SECRET_KEY`.

### Интеграционные проверки

Тесты используют запущенный Compose и Chromium. Они создают отдельные аккаунты и мероприятия со случайными идентификаторами.

```bash
npm ci
npx playwright install chromium
npm test
```

При других портах задайте `EVENTPASS_TEST_URL` и `EVENTPASS_MAIL_URL`. Для повторной проверки в браузере с нуля можно использовать отдельный проект Compose с другими портами.

## Стек

| Что | Чем |
| --- | --- |
| Сборка | Vite 7 |
| UI | React 19 + TypeScript |
| Роутинг | React Router 7 |
| Данные с сервера | TanStack Query 5 (кэш, загрузка, мутации) |
| Сессия | React Context (`AuthProvider`) |
| Стили | CSS Modules + CSS-переменные из UI-кита (`src/styles/tokens.css`) |
| Иконки | lucide-react |
| QR | qrcode.react |

Redux и другие стейт-менеджеры не используются: почти всё состояние — это данные с сервера, их держит TanStack Query, а остальное (формы, вкладки) — локальный стейт компонентов.

## Запуск фронтенда на моках

Нужен **Node.js 20.19+** (проверено на Node 24, npm 11).

```bash
npm install
cp .env.example .env      # на Windows: copy .env.example .env  (необязательно — по умолчанию моки)
npm run dev
```

Откройте http://localhost:5173 (если не открывается — http://127.0.0.1:5173).

### Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | дев-сервер с hot reload |
| `npm run build` | проверка типов + продакшен-сборка в `dist/` |
| `npm run preview` | локально открыть собранный `dist/` |
| `npm run lint` | ESLint |
| `npm run typecheck` | только проверка типов |

Роль в EventPass зависит от мероприятия, а не от аккаунта: подробнее — в [docs/MOCKS.md](docs/MOCKS.md#роли-как-это-устроено). Текущую роль показывает жёлтая DEV-плашка в шапке.

На экране входа эти аккаунты подсказаны: клик по почте подставляет логин и пароль. В левом нижнем углу есть кнопка **«Демо»**: вход в один клик, ссылки на страницы мероприятий и «Сбросить демо-данные».

Публичные страницы: `/e/it-ds-2025`, `/e/devfest-2026`.

Пошаговые сценарии для всех ролей, где лежат данные и что делать, если не входит, — в [docs/MOCKS.md](docs/MOCKS.md).

## Структура

```
src/
  api/            доступ к данным — единственное место, которое знает про бэкенд
    contract.ts   интерфейс Api (все методы + REST-эндпоинты)
    types.ts      доменные типы (DTO)
    http/         реализация на fetch для настоящего бэкенда
    mock/         моковая реализация + демо-данные
  app/            провайдеры, роутер, guards
  features/       хуки TanStack Query по доменам (useMyTickets, useScan, …)
  layouts/        шапка, подвал, каркас страниц, демо-панель
  pages/          экраны
  shared/ui/      UI-кит: Button, Input, Badge, Segmented, Dialog, …
  shared/lib/     форматирование дат, файлы
  widgets/ticket/ QR билета, полноэкранный QR
  styles/         токены и глобальные стили
docs/             документация проекта
```
