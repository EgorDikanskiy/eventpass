# Экраны и маршруты

Соответствие экранов MVP макету Figma (страница «Page 1», секции 01–04). Секция 05 «План-максимум» и 99 «Архив» не реализуются.

## 01 · Гость (без входа)

| Макет | Маршрут | Файл |
| --- | --- | --- |
| Страница мероприятия (по ссылке) | `/e/:slug` | `pages/event/EventPage.tsx` + `RegistrationCard.tsx` |
| Билет после регистрации без аккаунта | `/e/:slug/ticket/:ticketId?token=…&created=1` | `pages/event/GuestTicketPage.tsx` |
| Вход: почта уже зарегистрирована | `/login` (с `state.pendingRegistration`) | `pages/auth/LoginPage.tsx` |
| Вход | `/login?returnUrl=…` | `pages/auth/LoginPage.tsx` |
| Регистрация аккаунта | `/register` | `pages/auth/RegisterPage.tsx` |

## 03 · Волонтёр

| Макет | Маршрут | Файл |
| --- | --- | --- |
| Мои мероприятия: вкладка «Волонтёр» | `/events?tab=volunteering` | `pages/myEvents/MyEventsPage.tsx` |

## Навигация и защита

- Шапка гостя: логотип, «Войти», «Регистрация». Шапка авторизованного: «Мои билеты · Мои мероприятия · Профиль», аватар.
- `/` → «Мои билеты» для вошедшего, «Вход» для гостя.
- Закрытые маршруты обёрнуты в `RequireAuth`: гость попадает на `/login?returnUrl=…` и после входа возвращается.
- Нет прав на мероприятие (чужой дашборд, сканер без прав) → уведомление и переход в «Мои мероприятия».

## Отклонения от макета

- Добавлено поле «Описание» в форму мероприятия — без него публичная страница пустая.
- В конструкторе анкеты можно выбрать тип вопроса (текст / выбор из списка), отметить обязательность и задать варианты — в макете это показано только списком.
- «Отменить регистрацию» — вторичная ссылка под действиями билета (в заметке макета: «кнопки нет — добавить вторичной»), с диалогом подтверждения.
- Экран «Волонтёры мероприятия» и мобильные версии сделаны по заметкам и UI-киту, без попиксельной сверки.
